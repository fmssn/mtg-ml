Next-actions fine-tunes

Each arm resumes the overnight self-play checkpoint (8.4M games) and trains 1M more games with one change from the next-actions list. All arms run the fixed engine (attacker declaration) and the value clamp. Every 250k games each plays 1,000 benchmark games as Jund against the blue Delver bot, sampled and greedy, plus 200 games against each rung of a fixed ladder of overnight snapshots (1M, 3M, 5M, 8M games) for an Elo. Gold line: the starting checkpoint on 2,000 games.
